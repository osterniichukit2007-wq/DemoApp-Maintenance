\# DemoApp-Maintenance



Навчальний проєкт для практичної роботи № 57 «Супровід програм».



Консольний застосунок на C# (.NET), на якому відпрацьовується процес супроводу ПЗ у Git:

\- гілка `dev` — основна розробка;

\- гілка `master` — лише готові відтестовані версії;

\- гілки `release/\*` — підготовка релізів.
